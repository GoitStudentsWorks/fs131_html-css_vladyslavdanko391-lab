# Booksy project

## Запуск

1. Встанови Node.js сумісної версії (для Vite 8 потрібен сучасний Node.js).
2. У корені проєкту виконай `npm install`.
3. Запусти локальний сервер командою `npm run dev`.
4. Для production-збірки виконай `npm run build`.

## Що виправлено

- `main.js` вставляє HTML partials перед запуском `header.js` та `events.js`.
- Зображення Events імпортуються через Vite, тому шляхи коректно працюють із `base: "/booksy/"`.
- SVG-іконки Events використовують наявні в `src/assets/icons/icons.svg` ID `icon-arrow-left` та `icon-arrow-right`.
- Стилі Events підключені через `src/css/index.css`.
- На мобільних пристроях показується одна картка; доступні свайп, стрілки та крапки.
- Форма реєстрації відкривається для вибраної події та закривається хрестиком, Escape або кліком по фону.

Форма зараз демонстраційна: дані виводяться в консоль браузера. Для реального надсилання потрібен backend/API.
